# Vui Voi Nhau Games Studio

A responsive static website ready for GitHub Pages. No build step or server required.

## Publish on GitHub Pages

1. Create a **public** GitHub repository named `vui-voi-nhau-games` (or any name).
2. Upload **all files and the `assets/` folder** from this package to the repository root (or push them with Git).
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, select **Deploy from a branch**; choose **main** and **/(root)**; save.
5. Once GitHub finishes publishing, open `https://YOUR-USERNAME.github.io/vui-voi-nhau-games/` (substitute your GitHub username and repo name).

If you instead create a repository named `YOUR-USERNAME.github.io`, your site will appear at `https://YOUR-USERNAME.github.io/`.

## Before making the site public

- Review and finalize `privacy.html` before using it as an **app** privacy-policy URL. The included draft is intentionally **not** a claim about your apps' actual data practices.
- Update the status of Mystery Tile Sort when it is released, and add a verified Play Store link.
- Confirm your public studio contact address is `vuivoinhau2025@gmail.com`.
- Replace imagery/text as your game catalog grows.

## Local preview

Open `index.html` in a browser or run `python3 -m http.server 8000` from the folder and visit `http://localhost:8000`.
